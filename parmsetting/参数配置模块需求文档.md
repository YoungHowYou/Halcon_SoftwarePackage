# 参数配置模块需求文档



## 1. 数据结构规范

### 1.1 层级结构

配置文件采用**树形结构**，从顶层向下递归：

```
配置文件
├── 顶层模块（如 AI、检测参数）
│   ├── 子模块（如 初始化设置、隐裂、破片分割）
│   │   ├── 参数项（末端节点，含 Competence/Type/Limit/Value 四字段）
│   │   └── 参数项
│   └── 参数项（允许子模块层直接挂参数项，如"半片方向选择"）
└── 顶层模块
```

**关键规则**：层级深度不固定，分组节点下既可以挂下一级分组，也可以直接挂末端参数项。解析器可以通过判断"节点是否包含 `Type` 字段"来区分分组与末端参数：

- 含 `Type` → 末端参数
- 不含 `Type` → 分组，继续递归

### 1.2 末端参数的统一字段

每个末端参数必须包含以下四个字段，缺一不可：

| 字段 | 含义 | 类型 |
|---|---|---|
| `Competence` | 操作权限等级 | int |
| `Type` | 数据类型 | string（枚举） |
| `Limit` | 取值约束 | 取决于 Type |
| `Value` | 当前生效值 | 取决于 Type |

### 1.3 支持的数据类型（Type）

| Type 值 | 含义 | Limit 格式 | Value 示例 |
|---|---|---|---|
| `int` | 整数 | `[min, max]` 闭区间 | `60` |
| `float` | 浮点数 | `[min, max]` 闭区间 | `3.5` |
| `bool` | 布尔 | `""`（空） | `"TRUE"` 或 `"FALSE"` |
| `string` | 任意字符串 | `""`（无约束） | `"Breakage|Cracks"` |
| `string_enum` | 字符串枚举 | `["选项1","选项2",...]` | `"GPU"` |
| `int_enum` | 整数枚举 | `[1, 2, 4, 8]` | `4` |
| `float_enum` | 浮点数枚举 | `[0.5, 1.0, 1.5, 2.0]` | `1.5` |
| `int[]` | 整数数组（变长） | `[min, max]`，作用于**每个元素** | `[10, 20, 30]` |
| `float[]` | 浮点数数组（变长） | `[min, max]`，作用于**每个元素** | `[0.5, 1.5, 2.5]` |
| `string[]` | 字符串数组（变长） | `""`（无约束） | `["A","B","C"]` |
| `directory` | 目录路径 | `""` | `"./json"` |
| `path` | 文件路径 | `""` | `".\\mask.hobj"` |


### 1.4 权限等级（Competence）

| 等级 | 角色 | 权限 |
|---|---|---|
| `0` | 操作员 | 仅可见，不可编辑 |
| `1` | 产线工程师 | 可编辑日常调优参数 |
| `2` | 系统工程师 | 可编辑算法相关参数 |
| `3` | 管理员/开发 | 可编辑所有参数（含底层阈值） |

数字越大权限越高。UI 应根据当前登录用户的等级，自动隐藏或锁定高于其等级的参数项。

## 2. 功能需求

### 2.1 配置文件读写

- 加载指定路径的 JSON 配置文件，递归解析为内存树。
- 保存内存树回写到 JSON 文件，保留原始字段顺序。
- 支持加载失败时给出明确错误（语法错误、缺字段、Type 未知等）。

### 2.2 参数 UI 自动渲染

UI 框架根据节点 `Type` 字段自动选择控件：

| Type | UI 控件 |
|---|---|
| `int` / `float` | 数字输入框 + 滑块（带 min/max 提示） |
| `bool` | 开关 / 复选框 |
| `string` | 单行文本框 |
| `string_enum` / `int_enum` / `float_enum` | 下拉选择框（仅可选 Limit 列表中的值） |
| `int[]` / `float[]` / `string[]` | 多输入框组合，每个元素一个输入框；右侧带 `＋` / `−` 按钮，点击 `＋` 追加一项、`−` 删除最后一项（或每行独立删除按钮）。新增项的默认值：数字类型用  Limit 下限，字符串用空串 |
| `directory` | 目录选择对话框 |
| `path` | 文件选择对话框 |

分组节点渲染为可折叠面板或 Tab，层级深度不限。

### 2.3 输入校验

- `int` / `float`：值必须落在 `Limit` 区间内。
- `string_enum` / `int_enum` / `float_enum`：值必须为 `Limit` 列表中的某一项（区分类型严格匹配，不允许自由输入区间外的值）。
- `int[]` / `float[]`：数组的**每一个元素**都必须落在 `Limit` 区间内.
- `string[]`：元素无内容约束；如需限制元素数量或单个元素格式（如非空、长度上限）。
- `directory` / `path`：保存时检查路径是否存在，不存在则警告（非阻断）。

### 2.4 权限控制

- 模块启动时**从用户权限模块**获取当前登录用户的 `Competence` 等级（不自行管理用户登录）。
- 渲染时：参数 `Competence` ≤ 当前用户等级 → 可编辑；> 当前等级 → 只读或隐藏（策略可配置）。
- 保存时：再次校验权限，禁止越权写入。

### 2.5 多配置文件管理

- 同时支持多份配置文件并存（按设备/产线/工程命名，如 `导片机.json`、`意大利.json`）。
- 提供切换、复制功能。


### 2.6 多语言支持（可选）

- 参数键名（如 `隐裂`、`Breakage`）通过独立的多语言映射表显示，不影响 JSON 内部存储。
- 显示语言可在运行时切换。




## 3. 非功能需求

- **性能**：单份配置文件参数量级 ≤ 1000 项时，加载与渲染应在 500ms 内完成。
- **健壮性**：单个参数解析失败不应导致整个文件加载失败，应记录错误并继续。
- **可追溯性**：每次保存应记录修改人、修改时间、修改前后的 diff，便于产线问题回溯。
